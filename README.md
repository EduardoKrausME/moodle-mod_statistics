# mod_statistics - Estatística rápida

Atividade Moodle para cálculo instantâneo de estatística descritiva a partir de uma sequência de números.

## Resultados

- Quantidade e soma
- Média
- Mediana
- Moda (inclusive multimodal)
- Mínimo e máximo
- Amplitude
- Variância populacional ou amostral
- Desvio padrão populacional ou amostral
- Valores ordenados

Os números digitados pelo usuário são processados somente no navegador e não são gravados no banco de dados.

## Entrada

Aceita valores separados por espaço, quebra de linha, tabulação, ponto e vírgula e listas com vírgula. Decimais podem usar ponto ou vírgula. Por causa da ambiguidade de `1,2`, esse formato isolado é interpretado como o decimal 1,2; para uma lista de dois inteiros use `1, 2`, `1 2`, `1;2` ou um valor por linha.

## Compatibilidade

Moodle 4.5 ou superior.
